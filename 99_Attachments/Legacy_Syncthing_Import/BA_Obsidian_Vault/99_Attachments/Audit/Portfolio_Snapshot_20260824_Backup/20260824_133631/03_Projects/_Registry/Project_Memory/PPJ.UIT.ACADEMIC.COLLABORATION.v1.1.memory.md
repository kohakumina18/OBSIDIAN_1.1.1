# Project Memory: PPJ.UIT.ACADEMIC.COLLABORATION.v1.1

## One-Line Understanding

Academic collaboration initiative between PPJ Group and UIT Faculty of Information Systems to connect real business problems with thesis, course projects, contests, mentoring, and student prototypes.

## Business Meaning

Creates an innovation and talent pipeline while safely packaging PPJ practical problems for academic use.

## Outcome

Prepare collaboration topics, classify fit for thesis/course/AISC/prototype/internal-only, and coordinate with UIT contacts.

## What This Project Is

- Academic partnership and innovation pipeline.
- Topic/backlog preparation for UIT collaboration.
- Possible AISC sponsor/judge/mentor/problem-provider track.
- Possible PPJ-themed academic contest if resources and format are clear.

## What This Project Is Not

- Not a vendor solution project.
- Not production development by students.
- Not permission to share sensitive company data.

## Key Users

PPJ Group, Madame Hồng Phương, Khoa, UIT Faculty of Information Systems, cô Nhạn, cô Phụng, lecturers, students.

## Systems / Data

Use sanitized PPJ business problem statements; use masked or synthetic data unless approved.

## Current Phase / Status

Backlog / Partnership Discussion.

## Known Risks

- Sensitive data exposure.
- Topics too large for students.
- Unclear IP/prototype ownership.
- Need PPJ internal owner per topic.

## Decisions Needed

- Which PPJ topics are safe and suitable for UIT.
- Whether PPJ joins AISC as sponsor/judge/mentor/problem provider.
- Whether any PPJ-themed contest should be pursued.

## Next Actions

- Prepare topic list.
- Classify topics by thesis/course/AISC/prototype/internal-only.
- Work with cô Phụng on collaboration model.
- Review AISC sponsorship file if needed.

## Do Not Drift Rules

- Do not group with vendor projects like QSee, NUNOX, Stratova.
- Do not expose sensitive PPJ/customer/system data.
- Do not treat student prototypes as production systems.
