# Project Knowledge Detail

## Executive Summary

`PROD.COWASH.v2.0` is a wash-process data project intended to pull data from Cowash software and build realtime dashboard/reporting for wash operations. It is currently On Hold / Re-scope because technical approach, source data, API/export access, owner, and KPI requirements are not yet clear.

Potential dashboard data includes order/style, wash type, process status, start/end time, output quantity, delay/downtime, machine/line, operator/team, issue, and rework if available.

Next work is to survey Cowash data/API/export, identify stakeholders and users, define wash KPIs, clarify overlap with Wash Sampling Portal, and decide whether to continue, hold, or redesign.
