# Project Memory: FD.Datamart.v2.2

## One-Line Understanding

FD / fabric datamart using Directus with QR design or QR information for hanger usage.

## Current Outcome

Manage FD/fabric/hanger data in Directus with QR support for hanger operation and sample visibility.

## Current Status

Stabilize / onboarding. QR Format Designer is complete; training session 3 completed; feedback is being gathered.

## Latest Update Summary

FD and CPD are separated. FD is Directus + QR hanger scope. Latest state: QR Format Designer complete, training session 3 done, feedback collection in progress.

## What This Project Is

FD/fabric/sample/hanger data visibility and QR hanger information support.

## What This Project Is Not

Not CPD.Datamart.v1.1, not 3D Design image search, not 3D sample library.

## Key Users

FD users, fabric sample / hanger users, QR hanger operators.

## Systems / Data

Directus, QR Format Designer, QR design or QR information module, fabric/sample/hanger data.

## Current Phase / Status

Stabilize / onboarding.

## Known Risks / Blockers

Feedback consolidation, QR link stability, Directus data quality, owner handover, and onboarding support.

## Decisions Needed

Confirm final Directus collections, QR format governance, owner, and production support model.

## Next Actions

Collect training feedback, adjust Directus/QR format rules, and finalize support handover.
