## Executive Summary

`PROD.IOT.CHuyenTreo.v1.0` is a production IoT/dashboard project that pulls data from hanging-line systems to build realtime or near-realtime dashboards and reports for production visibility.

The dashboard should support production monitoring through metrics such as output quantity, efficiency, downtime, line status, target vs actual, WIP if available, operation/process status, and time-based production trends.

Current status is Development, around 50%, with Linh as technical owner. Main risks are data source stability, KPI agreement, refresh delay, production validation, and device/system integration clarity.
