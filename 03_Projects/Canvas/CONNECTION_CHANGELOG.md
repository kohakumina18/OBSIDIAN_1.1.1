## Line types

INTEGRATION (green, solid) confirmed · PLANNED (orange, dashed) planned / in development · DATA (blue, dashed) data
dependency · KNOWLEDGE (cyan, dotted) knowledge / RAG / reference · AFFINITY (grey, dotted) business relationship only.
`PRIMARY` marks a project's main module; lines of closed projects are grey and say `historical`.
Project lines are hover-only (PPJ Canvas Focus plugin), so the former one-AFFINITY-line-per-project rule is retired.
