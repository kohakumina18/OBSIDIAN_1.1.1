# Capture and organize

Use when the user asks to process an inbox, organize rough notes, extract ideas, or clean up an existing note. Do not use for generating a formal BRD or analyzing a meeting transcript when a more specific skill fits.

## Procedure
1. Read the source and inspect related existing notes, parent-folder instructions, note properties, and vault naming conventions.
2. Identify the core subject, note type, owner/project (only if evidenced), date (only if evidenced), current action, and source references.
3. Search for an existing canonical note; prefer small updates with links over creating a near-duplicate.
4. Propose a destination and minimal property set consistent with the vault. Keep raw evidence discoverable.
5. Create or edit only requested items, favoring precise changes. For bulk moves/renames/deletions, request confirmation first.
6. Add 2–5 meaningful `[[wikilinks]]` only when supported; distinguish unresolved references from links that definitely exist.

## Output
- Condensed content: context, insights, decisions, action items, questions.
- Minimal metadata rather than speculative frontmatter.
- Links to source and related concepts.
- A short change log describing which files were actually changed.
