# Project weekly review

## Procedure
1. Ask for the project/scope and date range only if missing and essential; otherwise use the provided context.
2. Search relevant project notes and recent meeting/action items. Do not assume a task is complete because it has an old due date.
3. Reconcile most recent status with prior open items, and call out unresolved or contradictory claims.
4. Report a concise table: workstream | goal/output | verified status | latest progress | next step | blocker/risk | owner/date if known.
5. Separate accomplishments, new decisions, dependencies, risks, and management asks.
6. Add suggested follow-ups clearly labeled as recommendations, not established commitments.

## Rules
- No invented completion percentages or dates.
- If missing evidence, say `Status unknown — validation needed`.
- Reuse existing project notes and links; do not create duplicate status pages without request.
