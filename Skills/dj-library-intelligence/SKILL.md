# DJ track and set intelligence

## Procedure
1. Use observed track metadata from provided files; do not guess measured BPM/key or claim to have listened to unavailable audio.
2. Distinguish **verified metadata** from **inferred style** and **recommendation**.
3. Describe genre/subgenre, rhythmic character, hook, density, energy level, crowd response role and suggested set phase.
4. Identify transition candidates using BPM/key/energy only when values are available; flag uncertain compatibility.
5. Preserve original tags/measurements unless explicit evidence justifies a reclassification.
6. For a proposed set, explain narrative flow, opening, energy build, peaks, release and closing.

## Output
Compact track or set table with evidence/confidence flags, duplicates/metadata conflicts and recommended next checks.
