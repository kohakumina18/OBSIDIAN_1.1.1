# ESL and IELTS teaching workbook

## Procedure
1. Establish skill (speaking, writing, vocabulary), learner level, session goal and scenario when provided.
2. For speaking/workplace conversation, structure: **Insight → Vocabulary/Collocations → Sentence Framework → Applying Exercises → Final Sum-up Exercise**.
3. For IELTS Writing, pair each teaching segment **Knowledge/Insight → Applying Exercise**, progressing from sentence → argument chain → paragraph → full response.
4. Lead with natural, reusable English. Add concise Vietnamese explanation where it helps Vietnamese learners.
5. Make exercises progressive and ready for classroom delivery; keep examples adult-appropriate and connected to work or life.
6. Provide model answers when requested; do not present generated responses as official examiner scoring.
